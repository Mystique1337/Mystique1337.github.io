START LOCAL SERVER:
    cd "path/to/portfolio"
    python -m http.server 8000
    
    Then open: http://localhost:8000/index-new.html

STOP SERVER:
    Press: Ctrl + C

HARD REFRESH BROWSER:
    Windows: Ctrl + Shift + R
    Mac:     Cmd + Shift + R

CREATE BACKUP:
    Copy-Item index-new.html index-new.backup.html

│ ✅ UPDATE WORKFLOW                                                      │
└─────────────────────────────────────────────────────────────────────────┘

    1. Open index-new.html in VS Code
    2. Find the section you want to update
    3. Copy template from above
    4. Paste and modify
    5. Save file (Ctrl + S)
    6. Refresh browser (Ctrl + Shift + R)
    7. Check if it looks good
    8. Commit to Git (optional):
       git add .
       git commit -m "Updated experience"
       git push origin main

┌─────────────────────────────────────────────────────────────────────────┐
│ 🆘 TROUBLESHOOTING                                                      │
└─────────────────────────────────────────────────────────────────────────┘

    ❌ Changes not showing?
    ✅ Hard refresh: Ctrl + Shift + R
    
    ❌ Image not loading?
    ✅ Check file path is exactly right
    ✅ Check file actually exists in folder
    
    ❌ Layout broken?
    ✅ Check all <div> tags are closed: </div>
    ✅ Check no missing quotes: href="..."
    
    ❌ Colors not changing?
    ✅ Edit assets/css/modern.css
    ✅ Clear browser cache
    
    ❌ Formspree not working?
    ✅ Replace YOUR_FORMSPREE_ID with actual ID
    ✅ Get free ID from formspree.io
